# 桌面待办

一个不需要安装任何依赖的 Windows 桌面任务清单，采用半透明马卡龙风格界面。

## 使用方法

双击 **`启动桌面待办.vbs`** 即可打开。

- 在顶部输入任务，按回车或点击加号添加。
- 可以在添加任务时填写 DDL（截止日期），格式为 `YYYY-MM-DD`。
- 直接点击任务文字进行编辑，按回车保存。
- 每条任务下方都可以直接填写、修改或清除 DDL；无效日期会标红，逾期日期也会显示为红色。
- 勾选任务表示完成。
- 点击任务右侧的“×”删除。
- “置顶”可以让窗口保持在其他窗口上方。
- 底部可以开启或关闭开机自动启动。
- 窗口采用半透明背景，可以看到后面的桌面内容。

任务会自动保存在程序目录下的：

`data\tasks.json`

窗口位置、大小和置顶状态也会自动保存。

## 关闭与重新打开

点击右上角“×”会关闭程序。再次双击 `启动桌面待办.vbs` 即可打开，已有任务不会丢失。
